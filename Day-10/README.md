# Day 10 - 100 Days of Code

## Questions

1. Write a C program to classify a triangle as Equilateral, Isosceles, or Scalene based on its side lengths.

2. Write a C program to display the day of the week based on a number (1-7) using switch-case.

## Concepts Used

- If-else statements
- Logical operators
- Switch-case
- Break statement
